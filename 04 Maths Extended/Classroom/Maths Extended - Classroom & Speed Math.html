Exponents & Rational Powers

Classroom worked examples and practice on simplifying powers, quotients, and evaluating fractional roots.

Key Rules from Class

  • Fractional Exponents: a1/n = n√a (the n-th root of a), and am/n = (n√a)m. Denominator is root index, numerator is power.
  • Negative Exponent: x-n = 1 / xn. E.g., 27-2/3 = 1 / (3√27)2 = 1/9.
  • Zero Exponent: x0 = 1 (for any base x ≠ 0).
  • Power of a Power: (xa)b = xab. When multiplying same bases: xa · xb = xa+b.
High-Yield Concept

The Absolute Value Rule: Why √(x²) ≠ x

The principal root √ is strictly non-negative. This is one of the easiest ways to lose marks on Grade 9 Extended tests!

The Golden Rule

  • Even Roots (n is even): n√(xn) = |x|. Absolute value bars are required because x could be negative! (e.g. √((-5)²) = √25 = 5 = |-5|).
  • Odd Roots (n is odd): n√(xn) = x. No absolute value needed because odd roots preserve the sign (e.g. 3√(-8) = -2).
  • When can you drop the bars? If the inside quantity is guaranteed ≥ 0 (like √(x4) = x², because any square is ≥ 0).
