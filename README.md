## 🛠️ GitHub Setup & Publishing

### Step 1: Push to GitHub via VS Code
1. Open this folder in VS Code (`code "C:\Users\wayne\Desktop\Devon\IB MYP Grade 9"`).
2. Go to the **Source Control** tab (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd>).
3. Click the blue **Publish Branch** button and select **Publish to GitHub public repository**.

### Step 2: Enable GitHub Pages
1. Open your new repository on GitHub: `https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>`
2. Go to **Settings** → **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, Folder: `/ (root)`
   - Click **Save**.
4. In 1–2 minutes, your live site will be ready at:
   ```plaintext
   https://<YOUR_GITHUB_USERNAME>.github.io/<REPO_NAME>/
   ```
